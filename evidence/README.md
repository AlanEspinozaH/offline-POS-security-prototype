# Evidencia experimental

Este directorio contiene evidencia preliminar del prototipo de proyec de tesis 1.

## Estructura

- `curated/`: conjuntos de resultados revisados y conservados para la redacción académica.
- `smoke/`: comprobaciones técnicas mínimas usadas durante el desarrollo.

## Exclusiones

No se incluyen:

- bases SQLite generadas durante las corridas;
- almacenes de claves;
- sales o propiedades criptográficas locales;
- directorios `run-*`;
- contenidos de `build/` o `target/`;
- historiales manuales del POS.
